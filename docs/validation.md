# 验证摘要与限制

公开包保留可运行的源码测试，排除包含环境拓扑、资源标识和原始请求样本的私有运行证据。

|层次|已观察到的结果|不能外推的结论|
|---|---|---|
|简单功能/构建|Go单元、vet、无C检查，Linux amd64静态二进制、scratch镜像和Helm模板已有通过记录|不替代真实内核与节点验证|
|ACK测试|HTTP、HTTP/2、Dapr自身mTLS关闭的gRPC、Pod变更、Service路径及染色头跨服务有定向验收|不代表所有Istio/Dapr/内核版本、EKS或生产均兼容|
|稳定性|一次500QPS、40分钟、5%染色的受保护测试取得通过记录|完整共享节点故障矩阵仍有未验证项|
|1000QPS|曾因节点CPU保护提前停止|没有完成1000QPS/40分钟长稳验收|
|Java/Nacos|Spring HTTP跨服务标记传递、配置更新，以及显式Nacos HTTP查询染色有通过记录|原Nacos SDK后台gRPC监听没有因此染色|
|数据库/应用TLS|仍有实现和验证缺口|不宣称已支持MySQL/Redis因果关联采集或应用自身TLS明文解密|

以上为对私有历史验收的摘要，不是本次公开包新做了一轮云测试。公开候选清理后的实际构建/扫描状态见[公开发布检查](../PUBLIC_RELEASE.md)。

测试fixtures均为合成内容，含明显占位的Authorization/Cookie字段，用于验证解析和输出行为；不是生产令牌。默认单元测试不访问云集群，Linux内核/本地集群测试有显式条件，未运行项按skip处理。真实可靠性、资源和故障验证应在批准的隔离测试环境开展。
